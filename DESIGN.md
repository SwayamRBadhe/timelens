# TimeLens design
Warm ivory paper, deep ink, oxblood actions, muted olive geographic accents. Locally bundled Newsreader display type and Source Sans 3 text. Fine rules, large date typography, editorial columns, square-cornered controls, generous but purposeful spacing.
Landing mode: Persuade. A date input is the primary action; a typographic historical dispatch previews the experience. Date and search mode: Operate/Read. A compact filter rail and readable event dispatches prioritize exploration.
Accessible focus rings, native date controls, labeled inputs, source links, reduced motion, responsive single-column layout. Event details expand in place. System dark mode uses the same hierarchy with warm ink surfaces.
